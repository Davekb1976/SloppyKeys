# Contributing

Short version: don't. The source is public so you can read it, build it, and change your
own copy. It isn't public as an invitation to collaborate.

**Pull requests are closed unread.** Not a judgement on the patch — this is a
single-author project and reviewing, testing and maintaining someone else's change costs
more than the change is worth here. Every fix has to be verified against a live game on a
real screen, which nobody but the author can do.

**Issues are off.** There's no support channel and no bug tracker.

You're welcome to fork it. Keep the licence notice, keep it noncommercial, and it's yours
to take wherever you like.

If something in the code is plainly wrong and you'd rather say so than fork, the licence
doesn't require you to and neither does anyone else.
