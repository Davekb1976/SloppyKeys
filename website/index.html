      Features
      
Built for a grind that doesn't need you

      
Every part of it exists because the manual version got old. No cloud, no account, no launcher.

    


    

      

        

          
        

        
Roblox docked inside the app

        

          The game keeps its own window; SloppyKeys punches a rounded hole in its frameless
          shell and parks Roblox exactly behind it. Pixels and clicks fall straight through,
          so you watch the run in the same window you control it from.
        

        
    
          
  • Client area pinned to 1152×756 for stable coordinates
    • 
          
  • DPI scaling disabled — 1 logical pixel is 1 real pixel
    • 
          
  • Minimize-safe: geometry sync guards against off-screen flings
    • 
        

      


      

        

          
        

        
It looks, then clicks

        

          Screens get captured with mss and matched against cropped
          templates in OpenCV. Search regions keep matching fast and stop false hits
          elsewhere on screen.
        

      


      

        

          
        

        
Human-shaped input

        

          AutoHotkey v2 owns every click and keypress. Buttons get a real hover-glide and
          wiggle, and the carousel scrolls one wheel notch at a time — instant teleports
          get ignored by the game.
        

      


      

        

          
        

        
Macro Tester

        

          Run any single step in isolation with PASS / FAIL results, a coordinate and region
          picker overlay, and a template tester. Tuning stops being guesswork.
        

        Ctrl+T
      


      

        

          
        

        
Tunable without touching code

        

          Delays, keybinds, hard mode and the private-server link live in Settings and persist
          to settings.json. Gamemodes, maps, acts and coordinates are
          plain data tables, so new content is an edit, not a rewrite.
        

        

          Image-search cooldown
          Join wait
          Retry on load
          Hard mode
          Private server
        

      


      

        

          
        

        
Never freezes

        

          Clicks, sleeps and image searches run on worker threads, so the interface stays
          responsive while a step is mid-flight.

      FAQ
      
Straight answers

    


    

      

        Does it work on Mac or Linux?
        
No. SloppyKeys talks to the Win32 API to find, size and position the Roblox window, and it uses AutoHotkey for input. Both are Windows-only, and there is no cross-platform path planned.

      

      

        Why does the Roblox window get resized?
        
Every coordinate and template is captured at a 1152×756 client area with DPI scaling disabled. Pinning that size is what makes clicks land in the right place on any display — and it's why Windows display scaling has to be 100%: a template cropped at 100% scores as a different image at 125%.

      

      

        Can I add a map or tweak the timing?
        
Yes. Content lives in data tables — gamemodes, maps, acts, start sequences, images and search regions. Delays and keybinds are editable live in Settings and saved to settings.json.

      

      

        Does it run a full session on its own?
        
Yes. F1 walks the lobby, starts the stage, places your units, watches for the result and goes again. Queue up to three targets with a run limit each, and daily challenges preempt the queue while any are left. Every step is still runnable on its own in the Macro Tester when something needs tuning.

      

      

        Does it update itself?
        
If you want it to. It checks GitHub once per launch and tells you when there's a newer release; nothing downloads until you click. An installed copy can update in place, and the download is verified against the checksum published with the release. One toggle turns the whole thing off.

      

      

        Will this get my account banned?
        
Automation tools carry risk. SloppyKeys sends ordinary mouse and keyboard input and never touches game memory or network traffic, but it still automates play, which many games disallow. Use it knowing that.
